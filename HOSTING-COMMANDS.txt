🛠️ TROUBLESHOOTING
───────────────────────────────────────────────────────────────

Issue: "Cannot connect to API"
→ Wait 30 seconds (free tier wake-up)
→ Check VITE_API_URL in frontend environment
→ Verify CORS in server/index.js

Issue: "MongoDB connection error"
→ Check connection string password
→ Verify IP whitelist has 0.0.0.0/0
→ Ensure database user has read/write access

Issue: "No AI questions"
→ Check GEMINI_API_KEY in backend environment
→ View logs in Render dashboard
→ Verify API quota at https://aistudio.google.com
